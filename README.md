# Kapten Homebrew tap

Homebrew packages maintained by Kapten.

## Install the Kapten CLI

```bash
brew install --cask kapten-io/tap/kapten
```

Release automation in [`kapten-io/kapten`](https://github.com/kapten-io/kapten) updates the cask from artifacts published to [`kapten-io/cli`](https://github.com/kapten-io/cli).
